# 🐲 Bowser's Wrath — The Builder's Codex

A kid-friendly, step-by-step tutorial for building a realistic Bowser-themed roller coaster in Theme Park Tycoon 2 (Roblox).

**👉 [Open the tutorial](https://alexdorsch.github.io/bowsers-wrath-tutorial/)**

## What's inside

- Interactive top-down castle map with clickable zones
- 10 phases of build instructions with auto-saving checklists
- Decal Vault with one-click copy for Roblox asset IDs
- Pro tips, lighting guides, and a sequencer wiring walkthrough
- Unlockable "Quest Complete" victory screen at 100%

Single-file static site. No build step, no dependencies. Open `index.html` in any browser to view locally.
